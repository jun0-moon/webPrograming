# 체스의 세계 (The World of Chess)

이 프로젝트는 **체스의 규칙, 역사, 전략, 기물 소개** 등을 한눈에 볼 수 있는 정적 웹사이트입니다.  
웹프로그래밍 과제 및 포트폴리오 용도로 제작되었습니다.

---

## 📁 폴더 구조

```
webPrograming/
├── index.html           # 메인(홈) 페이지
├── gallery.html         # 체스 기물 소개 페이지
├── article.html         # 상세 규칙 & 전략 페이지
├── contact.html         # 문의/피드백 페이지
├── css/
│   └── style.css        # 통합 스타일시트
└── README.md            # 프로젝트 설명 파일
```

---

## 📝 주요 기능 및 특징

- **반응형 레이아웃**: PC/모바일 모두 보기 편한 구조
- **순수 HTML/CSS/JS**만 사용 (프레임워크 미사용)
- **체스 기물 소개**: 각 기물의 움직임, 가치, 역할 설명
- **상세 규칙 & 전략**: 체크, 캐슬링, 앙파상 등 규칙과 전략, 표/인용/다이어그램 포함
- **문의 폼**: 이메일, 문의 목적, 메시지 입력 가능 (실제 전송 X, 안내 메시지 표시)
- **접근성 및 가독성**을 고려한 디자인

---

## 💡 실행 방법

1. 이 폴더를 그대로 다운로드/복사합니다.
2. `index.html` 파일을 더블클릭하거나,  
   웹 브라우저(Chrome, Edge 등)에서 열면 바로 사용 가능합니다.
3. 별도의 서버나 설치 과정이 필요 없습니다.
