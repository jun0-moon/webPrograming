# ♟️ 웹사이트 '체스의 세계' - 프로젝트 설명서

## 1. 개요 (Overview)

이 프로젝트는 체스의 규칙, 기물, 전략, 그리고 문화적 영향력까지 다루는 종합 정보 웹사이트입니다. 순수 HTML, CSS, JavaScript를 사용하여 제작되었으며, 사용자가 체스에 대한 깊이 있는 지식을 쉽고 재미있게 탐색할 수 있도록 동적인 인터페이스를 구현하는 데 중점을 두었습니다.

## 2. 사이트맵 (Sitemap)

웹사이트는 총 4개의 주요 페이지로 구성되어 있습니다.

/ (root)  
├── 📄 index.html (홈)  
│ - 웹사이트의 첫인상을 결정하는 페이지.  
│ - 체스가 등장하는 미디어 콘텐츠 갤러리와 체스의 이점을 소개하여 흥미를 유발.  
│  
├── 📄 gallery.html (체스 기물 소개)  
│ - 6종류의 체스 기물(킹, 퀸, 룩, 비숍, 나이트, 폰)을 소개.  
│ - 사이드바 메뉴와 본문이 연동되어, 클릭 시 해당 기물의 상세 설명과 움직임 다이어그램을 동적으로 표시.  
│  
├── 📄 article.html (상세 규칙 & 전략)  
│ - 캐슬링, 앙파상 등 특수 규칙과 포크, 핀 등 고급 전술을 심도 있게 설명.  
│ - 사이드바 목차를 통해 원하는 정보로 빠르게 이동 가능.  
│ - JSON 데이터를 활용하여 역사적 명국의 기보를 동적으로 시뮬레이션.  
│  
└── 📄 contact.html (문의하기) - 사이트 관련 피드백이나 질문을 남길 수 있는 정적 문의 폼 제공.

## 3. 디자인 의도 (Design Intent)

### 🎨 색상 및 폰트

- **주요 색상**: 안정감과 집중력을 주는 짙은 녹색(`--color-primary`)과 체스판의 클래식한 느낌을 주는 베이지색(`--color-secondary`)을 사용하여 신뢰감 있고 전문적인 분위기를 연출했습니다.
- **폰트**: 전체적으로 가독성이 뛰어난 'Inter' 웹 폰트를 사용하여 정보 전달의 명확성을 높였습니다.

### 📐 레이아웃 및 인터랙션

- **일관된 구조**: 모든 페이지에 `<header>`, `<nav>`, `<footer>`를 공통적으로 배치하여 일관된 사용자 경험을 제공합니다.
- **카드형 디자인**: 정보를 `.content-card` 단위로 명확하게 구분하여 가독성을 높이고, 마우스 호버 시 그림자와 입체 효과를 주어 시각적 재미를 더했습니다.
- **동적 콘텐츠**: JavaScript를 활용하여 `gallery.html`과 `article.html`의 사이드바 메뉴 클릭 시, 페이지 새로고침 없이 해당 콘텐츠만 동적으로 보여주어 사용자의 탐색 경험을 부드럽게 만들었습니다.
- **시네마틱 홈페이지**: `index.html`은 영화 포스터 갤러리 스타일을 채택하여, 정적인 정보 사이트를 넘어 사용자의 흥미를 끄는 시각적 스토리텔링을 시도했습니다.

## 4. 웹 접근성 (Accessibility)

모든 사용자가 정보에 쉽게 접근할 수 있도록 웹 표준을 준수하여 개발했습니다.

- **시맨틱 HTML**: `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>` 등 의미에 맞는 시맨틱 태그를 사용하여 스크린 리더 사용자가 콘텐츠의 구조를 명확하게 파악할 수 있도록 했습니다.
- **대체 텍스트**: 모든 `<img>` 태그에 구체적인 `alt` 속성을 제공하여 이미지를 볼 수 없는 사용자에게도 해당 정보를 전달합니다. 또한, 체스 다이어그램에는 `aria-label`을 통해 포지션 상황을 음성으로 설명합니다.
- **키보드 접근성**: 모든 내비게이션 링크와 버튼, 폼 요소는 키보드의 `Tab` 키만으로 순차적으로 접근하고 조작할 수 있습니다.
- **폼 접근성**: `contact.html`의 입력 필드에는 `<label>`을 명확히 연결하고, `aria-describedby` 속성을 통해 입력 힌트를 제공하여 스크린 리더 사용자도 폼을 쉽게 작성할 수 있도록 설계했습니다.
- **반응형 디자인**: `meta` 뷰포트 태그와 미디어 쿼리를 사용하여 데스크톱, 태블릿, 모바일 등 다양한 화면 크기에서 콘텐츠가 깨지지 않고 최적화된 형태로 보이도록 구현했습니다.

## 5. 기술적 의사결정: 레이아웃 구현 방식 비교

이 프로젝트의 레이아웃은 주로 **Flexbox**와 **Grid**를 사용하여 구현되었습니다. 과거에 많이 사용되던 `float`나 `inline-block` 대신 최신 기술을 선택한 이유는 명확한 장점 때문입니다.

### legacy 방식: `float` 와 `inline-block`

| 속성               | 원래 목적                          | 레이아웃 문제점                                                                      |
| :----------------- | :--------------------------------- | :----------------------------------------------------------------------------------- |
| **`float`**        | 이미지 주위를 텍스트로 감싸기 위함 | 부모 요소의 높이가 사라져 `clearfix` 핵(hack) 필요. 수직 정렬이 매우 복잡함.         |
| **`inline-block`** | 블록 요소를 인라인처럼 가로로 배치 | 요소 사이에 의도치 않은 공백(4px)이 생김. 아이템들의 높이가 다를 때 정렬이 까다로움. |

과거에는 위와 같은 문제점들을 해결하기 위해 복잡한 추가 코드를 작성해야 했습니다.

### Modern 방식: `Flexbox` 와 `Grid` (본 프로젝트 채택)

이 프로젝트에서는 다음과 같이 최신 CSS 레이아웃 기술을 적극적으로 활용했습니다.

- **Flexbox (1차원 레이아웃)**

  - **사용처**: `<header>`, `<nav>`, `.poster-card` 내부 콘텐츠 등 한 방향(가로 또는 세로)으로 요소를 정렬해야 하는 대부분의 컴포넌트.
  - **선택 이유**: 아이템 간의 간격 조절(`gap`, `justify-content`)과 수직 중앙 정렬(`align-items`)이 매우 직관적이고 간단하여, 복잡한 계산 없이 유연한 레이아웃을 만들 수 있습니다.

- **Grid (2차원 레이아웃)**
  - **사용처**: `.media-gallery-grid`, `.benefits-grid` 등 가로와 세로를 동시에 고려해야 하는 복잡한 그리드 시스템.
  - **선택 이유**: `repeat`와 `minmax` 함수를 활용하여 반응형 그리드 레이아웃을 손쉽게 구현할 수 있습니다. `float`로는 구현이 거의 불가능한 복잡한 구조도 명료한 코드로 작성 가능합니다.

**결론적으로, Flexbox와 Grid는 `float`나 `inline-block`의 문제점들을 완벽히 해결하고, 더 적은 코드로 더 강력하고 유연한 반응형 레이아웃을 구현할 수 있게 해주기 때문에 현대 웹 개발의 표준으로 사용되고 있습니다.**

## 6. 실행 환경 및 주의사항 (Execution Environment & Notes)

### 로컬 서버(Local Server) 환경 필수

이 프로젝트의 `article.html` 페이지는 JavaScript의 `fetch` API를 사용하여 외부 JSON 파일(`GAME.json`)의 데이터를 동적으로 불러옵니다.

웹 브라우저의 **동일 출처 정책(Same-Origin Policy)** 보안 규칙 때문에, 로컬 파일을 직접 열 경우(`file:///...` 프로토콜) `fetch` 요청이 차단되어 CORS(Cross-Origin Resource Sharing) 오류가 발생합니다.

**따라서 이 프로젝트의 모든 기능을 정상적으로 확인하려면 반드시 로컬 서버 환경에서 실행해야 합니다.**

### 추천 실행 방법: VS Code 'Live Server'

가장 간편한 방법은 Visual Studio Code 편집기의 **Live Server** 확장 프로그램을 사용하는 것입니다.

1. VS Code의 확장 프로그램 탭에서 'Live Server'를 검색하여 설치합니다.
2. 프로젝트 폴더를 VS Code로 엽니다.
3. `index.html` 파일을 우클릭한 뒤, **"Open with Live Server"**를 선택하여 실행합니다.
4. 자동으로 브라우저에 `http://127.0.0.1:5500`과 같은 로컬 서버 주소로 웹사이트가 열리며, 모든 기능이 정상적으로 동작합니다.
