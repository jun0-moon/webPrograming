# ♟️ 체스의 세계 (The World of Chess)

## 프로젝트 개요

본 프로젝트는 웹 프로그래밍 과제로 제작된 정적 멀티페이지 웹사이트입니다. 체스(Chess)의 기본적인 규칙부터 복잡한 전술과 전략까지, 사용자들이 명확하게 이해하고 학습할 수 있도록 **깔끔한 디자인**과 **동적인 상호작용**을 중심으로 구성되었습니다.

## 1. 사이트맵 (Sitemap) 및 페이지 구성

웹사이트는 총 4개의 필수 페이지와 공통 컴포넌트(Header/Nav/Footer)로 구성되어 있습니다.

| 파일명                 | 역할             | 주요 콘텐츠                                                                | 필수 과제 요소 충족                                                |
| :--------------------- | :--------------- | :------------------------------------------------------------------------- | :----------------------------------------------------------------- |
| `index.html`           | 홈 (Home)        | 체스 소개 및 역사, 사이트 안내                                             | 최소 4페이지 구성                                                  |
| `gallery.html`         | 기물 소개        | **6가지 체스 기물**의 특징, 장점, 단점 (이미지 기반 다이어그램, 동적 전환) | 최소 4페이지 구성                                                  |
| `article.html`         | 상세 규칙 & 전략 | **규칙, 전술, 전략** 심화 내용 (다이어그램, 표, 인용, Figure)              | 긴 글, 표, 인용, Figure                                            |
| `contact.html`         | 문의하기         | 가입/피드백 문의 폼                                                        | 문의 폼, HTML5 속성, 웹 접근성 (`<label for>`, `aria-describedby`) |
| `assets/css/style.css` | 스타일           | 모든 페이지의 스타일 통합 관리 (CSS 변수 사용)                             | 외부 CSS 통합                                                      |

## 2. 디자인 의도 및 스타일 가이드

### 2.1 디자인 컨셉: '차분함과 전문성'

- **색상:** 차분한 남청록색 계열(`--color-primary: #006d77`)과 베이지색 계열(`--color-secondary: #edd7a3`)을 메인 색상으로 사용하여 체스의 **지적이고 전문적인 분위기**를 표현했습니다.
- **레이아웃:** Flexbox 기반의 2단 레이아웃을 활용하여 콘텐츠 카드(`.content-card`)를 깔끔하게 배치했습니다.

### 2.2 주요 UX/UI 구현

- **동적 다이어그램:** `gallery.html` 및 `article.html`에서 **CSS Sprite Sheet**와 **JavaScript**를 결합하여 기물의 움직임과 규칙 상황을 시각적으로 구현했습니다.
- **이동 흔적:** 애니메이션 다이어그램에서 기물 이동 시, **이동 전/후 칸에만 하이라이트(`.moved-square`)**를 적용하여 포지션 변화를 쉽게 추적할 수 있도록 했습니다.
- **사이드바:** `article.html`에 `<aside>` 태그를 사용하여 **규칙/전술/전략** 계층 구조의 목차를 제공하고, 클릭 시 해당 내용이 전환되도록 구현했습니다.

## 3. 웹 접근성 (Accessibility) 구현 요소

본 웹사이트는 모든 사용자가 정보를 쉽게 이용할 수 있도록 다음 접근성 요소를 준수했습니다.

- **시맨틱 HTML5 태그:** `header`, `nav`, `main`, `footer`, `aside`, `figure`, `figcaption` 등 **의미론적 태그**를 적극적으로 사용하여 문서 구조를 명확히 했습니다.
- **보조 설명:** `aria-describedby` 속성을 사용하여 이메일 입력 필드의 형식을 안내했습니다.
- **표 접근성:** `<table>` 요소에 `<th>`, `scope="col"/"row"`를 명확히 사용하여 화면 낭독기가 표의 구조를 올바르게 인식하도록 했습니다.

## 4. \[가산점\] 레이아웃 기법 비교 분석 (Flexbox 채택 이유)

본 프로젝트는 CSS3의 표준 레이아웃 모델인 **Flexbox**를 사용하여 **반응형 2단 사이드바**와 **동적 콘텐츠 전환** 기능을 **안정적이고 유지보수가 용이한 구조**로 완성하였습니다. 이는 과거의 `float`나 `inline-block` 기법이 야기했던 **복잡한 높이 계산 문제**와 **불필요한 간격 문제**를 완벽하게 회피하는 현대적인 웹 개발 방식입니다.

#### 과거 레이아웃 기법과의 비교 요약

| 특징             | `float` 기법의 문제점                                                                   | Flexbox의 장점                                                        |
| :--------------- | :-------------------------------------------------------------------------------------- | :-------------------------------------------------------------------- |
| **높이 문제**    | 부모 요소가 플로팅된 자식 요소의 높이를 인식하지 못하는 **Float Collapsing** 문제 발생. | 부모 요소가 모든 자식 요소를 감싸므로 높이 계산이 정확함.             |
| **정렬**         | 수직 중앙 정렬이 매우 복잡함.                                                           | `align-items` 속성 하나로 간단하게 수직 중앙 정렬 가능.               |
| **요소 간 간격** | HTML 코드의 공백 문자 때문에 불필요한 마진이 생김.                                      | `gap` 속성을 사용해 간격을 정확히 제어하여 예측 불가능한 공백이 없음. |
